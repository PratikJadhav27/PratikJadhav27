## Projects

### Curalink — AI Medical Research Assistant
*3rd place, AI Hackathon (800+ participants)*

Fine-tuned `flan-t5-base` with LoRA (8K medical examples, 0.71% trainable params) to convert natural-language queries into PubMed MeSH boolean search terms. Hybrid RAG pipeline retrieves candidates from PubMed, OpenAlex, and ClinicalTrials.gov, reranks with MiniLM embeddings, and synthesizes answers with Groq Llama-3.3-70B, grounded in retrieved abstracts.

`FastAPI` `Flan-T5` `LoRA` `MiniLM` `Groq` `MongoDB` `React`

### LCD Defect Detection
*Alemeno Private Limited*

Built and annotated a 10K+ image dataset. Trained a CNN ensemble across 17 defect classes on Vertex AI, deployed via TensorFlow Serving in Docker. Improved detection accuracy through error analysis and retraining on hard-negative samples.

`CNN` `Vertex AI` `TensorFlow Serving` `Docker` `OpenCV`

### PDF Corpus Chat — Hybrid RAG
Hybrid retrieval combining BM25 and FAISS with reciprocal rank fusion. LLM-as-judge evaluation pipeline integrated into CI/CD via GitHub Actions to catch regressions before production.

`LangChain` `FAISS` `BM25` `GitHub Actions`

### Facial Emotion-Based Music Recommendation
Facial emotion recognition trained on 35K+ images across 7 emotion classes. Real-time recommendation engine using emotion fusion and feedback-driven personalization.

`TensorFlow` `Keras` `OpenCV` `Streamlit` `WebRTC`
