## 🚀 Work That Shipped

### 🏆 Curalink — AI Medical Research Assistant
> 3rd Place, AI Hackathon (800+ Participants)

Fine-tuned `flan-t5-base` with LoRA (8K medical examples, only 0.71% trainable params) to convert natural-language queries into PubMed MeSH boolean search terms. Built a hybrid RAG pipeline that retrieves ~250 candidates from PubMed, OpenAlex, and ClinicalTrials.gov, reranks with MiniLM embeddings, and synthesizes answers using Groq Llama-3.3-70B — grounded strictly on retrieved abstracts, no hallucinations.

`FastAPI` `Flan-T5` `LoRA` `MiniLM` `Groq` `MongoDB` `React`

---

### 🔍 LCD Defect Detection — 34% to 92% Accuracy
> Alemeno Private Limited

Built and annotated a 10K+ image dataset from scratch. Trained an ensemble of CNN and LLM models across 17 defect classes on Vertex AI. Deployed via TensorFlow Serving in Docker. After analyzing per-class error distributions and retraining on hard-negative samples, difficult-class detection improved from 54% to 81%.

`CNN` `Vertex AI` `TensorFlow Serving` `Docker` `OpenCV`

---

### 📄 Multi-Document Conversational AI
Hybrid RAG system combining FAISS and BM25 for retrieval. Set up an LLM-as-a-judge evaluation pipeline integrated into CI/CD via GitHub Actions to catch regressions before they hit production. Response relevance improved by ~25-30% over dense-only retrieval.

`LangChain` `Gemini` `FAISS` `BM25` `GitHub Actions`

---
